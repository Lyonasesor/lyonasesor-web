### Lenguaje de marca

Cinco principios de voz:

1. **Dignifica, no diagnostica.** No dices "tienes ansiedad". Dices "lo que sientes tiene nombre y tiene sentido".
2. **Cita, no opina.** Cada afirmación va respaldada por autor, estudio o mecanismo concreto.
3. **Propone, no promete.** No prometemos transformación instantánea.
4. **Habla del yo al tú.** No es impersonal. Es Álvaro hablándole a alguien concreto.
5. **Cierra con una sola puerta.** Cada pieza termina apuntando a una sola acción.

## 🚀 Instalación y desarrollo local

### Requisitos

- Navegador moderno (Chrome, Edge, Firefox, Safari)
- Servidor local para pruebas (Live Server, Python http.server, etc.)

### Clonar y ejecutar

```bash
git clone https://github.com/[usuario]/lyonasesor.git
cd lyonasesor
python3 -m http.server 8000
```

Abrir `http://localhost:8000` en el navegador.

### Producción

Los archivos se suben directamente al servidor. No hay proceso de compilación.
